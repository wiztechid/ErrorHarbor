SSH & SFTP Troubleshooting

Start with the stage where the connection actually fails. These five guides separate pre-auth transport, authentication, subsystem startup, chroot enforcement, and later SFTP session termination so you do not fix the wrong layer.

Choose the earliest stage that matches your evidence
1 · Before authenticationkex_exchange_identification: Connection Closed by Remote Host — pre-auth connection pressure, blocking, sshd, or network path.
2 · During authenticationToo Many Authentication Failures — offered identities and key selection before MaxAuthTries.
3 · Subsystem will not startSubsystem Request Failed on Channel 0 — requested SFTP subsystem and effective sshd configuration.
4 · Chroot explicitly rejectedBad Ownership or Modes for Chroot Directory — repair the exact path component without weakening the jail.
