HP Printer 79 Service Error: Find What Is Crashing the Printer

HP defines 79 Error / 79 Service Error as an internal firmware error on current support guidance. Do not jump straight to a factory reset. First see whether the printer can reach Ready with network and USB disconnected; that single test separates an internal/persistent failure from many external job, file or connection triggers.

⚡ Quick Fix — restart once, then isolate if Error 79 returns

Turn the printer off, wait at least 30 seconds, then turn it on. If Error 79 returns, power it off again and disconnect network and USB cables before the next boot. HP's current Error 79 procedure uses this isolation step before firmware checking.

Verify: Record whether the printer reaches Ready with external data connections removed.

Diagnose by when Error 79 returns

The useful question is not merely “is the firmware old?” It is what has to be present for the firmware error to recur? A printer that stays Ready while isolated gives different evidence from one that shows 79 before any external connection or job is restored.

79 only with one document or workflow?
Preserve that file/application/driver combination and compare it with a simple known-good job.

Verify: You can state exactly which stage reproduces the error: isolated boot, connection restore, or a specific job/workflow.

Fix path #1 — if the printer reaches Ready while isolated

Do not immediately reconnect every cable and release the whole queue. Clear or hold pending jobs on computers and print servers first. Reconnect one connection, confirm the printer remains Ready, then send one simple test page.

HP's guidance says intermittent Error 79 should be isolated to something specific in the environment, such as a particular file or connection type. This controlled reconnect makes that advice testable instead of guessing.

Verify: The printer stays Ready after one connection is restored and one simple test job completes.

Fix path #2 — if one file or print workflow triggers 79

If simple jobs work but one PDF, application output, scan/network workflow or driver path repeatedly triggers Error 79, stop treating the printer as universally broken. Preserve the reproducible trigger, then test a different supported output path or driver without changing several variables at once.

Recent HP community cases still show Error 79 tied to particular workflows, including specific PDF printing and network scan behavior. Those reports are useful as examples of why reproduction matters, but they do not prove that every Error 79 has the same cause.

Verify: The suspect workflow reproduces the error while a known-simple job does not.

Fix path #3 — check the exact model's current firmware

If the printer returns to Ready, HP recommends checking the installed firmware version and updating when a newer supported version is available. Use HP's support page for the exact printer model rather than a firmware package found for a similar model.

Firmware safety: keep power stable and do not interrupt an update. Record the existing firmware version first so the change is traceable.

Verify: After a supported update, repeat the same controlled test that previously reproduced Error 79.

What about DIMMs and older HP models?

Some older HP documentation distinguishes 79 Service Error from the generic 79 Error and associates it with incompatible DIMM/memory hardware. Do not remove memory based on that older model-specific guidance unless your printer actually has serviceable DIMMs and its own HP documentation calls for that step.

Verify: Before touching memory, confirm the exact model and its model-specific service documentation.

What not to do first

Do not factory-reset before testing whether Error 79 survives an isolated boot.Do not reconnect the network while a known bad queue is still waiting to resend.Do not change firmware, driver, network settings and print queue simultaneously—you lose the evidence.Do not assume every 79 or 79.xx variant has the same hardware cause across HP generations.Do not install firmware intended for another printer model or interrupt a firmware update.

Still getting HP Error 79?

If 79 persists while LAN/USB are disconnected, or it returns after HP's model-specific firmware path, collect evidence before escalating rather than cycling through destructive resets.
