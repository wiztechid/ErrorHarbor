Operating System Not Found in VMware: What to Check First

VMware can start the virtual machine, but its firmware cannot locate a bootable operating system. Check the virtual disk and boot path before changing advanced settings.

VMwareVMware WorkstationLast reviewed Sep 23, 2026
🎯 You’re likely in the right place if:
VMware starts but the guest operating system does not boot.The screen shows “Operating System Not Found”.The VM has or should have a virtual hard disk attached.
Difficulty: Easy–ModerateRisk: Low
⚡ Quick Fix — check the virtual hard disk first

Power off the VM, open its settings, and confirm the virtual hard disk is present, connected, and configured to connect at power on.

VM Settings → Hard Disk → Connected ✓

Verify: Start the VM again. If it reaches the operating-system loader, the disk connection was the cause.

Why this happens

VM firmware shows this message when it cannot find a bootable system. Common causes include a disconnected virtual disk, an empty disk, an unexpected boot order, or a firmware mode that does not match the installed operating system.

Diagnose before changing more

1
Is the virtual disk listed in VM settings?
If it is missing, stop here and identify the correct virtual disk before changing firmware settings.
2
Did this VM boot successfully before?
A previously working VM makes a connection or boot-path change more likely than a missing OS installation.
3
Is this a new VM?
Confirm that an operating system has actually been installed, or that installation media is mounted for the first boot.

Fix #2 — check the boot device and firmware path

If the virtual disk is attached, open the VM boot or firmware options and confirm the disk is available as a boot device. Avoid changing unrelated firmware settings.

🟡 Before changing configuration: note the current setting so it is easy to reverse.
Did Fix #2 work?

Still seeing the error?

If the disk is present and the boot order is reasonable, verify that the disk actually contains a bootable installation and that the VM firmware mode matches the way that operating system was installed.
